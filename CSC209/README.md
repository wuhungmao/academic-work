# CSC209 — Software Tools & Systems Programming

University of Toronto Mississauga | Winter 2023

Systems programming in C covering shell scripting, memory management, processes, and networking.

## Assignments

### A1 — Shell Scripting & Unix Commands
- `addPhotos` bash script: automates batch photo organization
- `hasWord`: searches for a word pattern across files

### A2 — Pointers & Memory Management
Five exercises in C covering pointer arithmetic, dynamic memory allocation, struct manipulation, and memory safety (no leaks verified with Valgrind).

### A3 — Multiprocess Handling & Signal Handling
Process creation with `fork()`/`exec()`, inter-process communication via pipes, and POSIX signal handling (`SIGCHLD`, `SIGINT`, etc.).

### A4 — Server & Client (Socket Programming)
TCP client-server architecture. Implemented a multi-client server using `select()` for I/O multiplexing without threads.

## Tech Stack
C, Bash, POSIX APIs, Valgrind, GDB
