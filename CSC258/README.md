# CSC258 — Simon Game

University of Toronto Mississauga | Winter 2023 | Grade: 90/100

Classic Simon memory game implemented entirely in RISC-V assembly language.

## Description
The game displays a random sequence of colored lights and sounds. The player must reproduce the sequence from memory. Each successful round adds one more step to the sequence.

**See `Simon game guide.pdf` for full gameplay instructions and implementation details.**

## Key Concepts
- RISC-V instruction set architecture
- Register management and calling conventions
- Memory-mapped I/O for display and input
- Subroutine design in assembly
- Stack frame management
