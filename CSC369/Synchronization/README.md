# Synchronization

CSC369 — Operating Systems | University of Toronto Mississauga

## Description
Concurrent programming assignments solving classic synchronization problems using POSIX threads.

## Topics Covered
- Mutex locks and condition variables
- Semaphores
- Producer-consumer problem
- Readers-writers problem
- Deadlock prevention

## How to Build
```bash
cd A2
make
./solution
```

## Tech Stack
C, Pthreads, POSIX synchronization primitives
