# Virtual Memory

CSC369 — Operating Systems | University of Toronto Mississauga

## Description
Implements virtual memory management subsystems in C, simulating OS-level page table management and page replacement.

**See `A3-REPORT/` for the full written analysis and performance measurements.**

## Key Concepts
- Multi-level page tables
- TLB simulation and miss handling
- Page replacement algorithms: LRU, Clock, FIFO
- Demand paging and page fault handling
- Working set model

## Tech Stack
C, POSIX, simulation framework
