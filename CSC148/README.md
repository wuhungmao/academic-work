# CSC148 — Introduction to Computer Science

University of Toronto Mississauga | Winter 2022

## Assignments

### A1 — Phone Company & Object-Oriented Programming
Models a phone company billing system. Practices class design, inheritance, and OOP principles in Python.

### A2 — File Compression (Huffman Algorithm)
Implements lossless file compression and decompression using the Huffman encoding algorithm.

**Key concepts:** Binary trees, greedy algorithms, bit manipulation, frequency analysis

**How to run:**
```bash
cd "a2 huffman algorithm and compression/starter"
python3 compress.py <input_file> <output_file>
python3 decompress.py <compressed_file> <output_file>
```

## Tech Stack
Python, OOP, data structures (trees, priority queues)
