a) vulnerability: buffer overflow 
sending over 1066 bytes could crash the service and get "Cannot determine peer address at tcpclientA.pl 
line 26" error. This indicate the attacker could overflow the buffer and cause remote service to crash.

To replicate this vulnerability, simply run "perl tcpclientA.pl". Then when it crashes, you would see count is x 
That mean the xinet server stop to function after inputting x bytes, which is larger than the size of buffer.

c) format string vulnerability

Inject %x, %s at appropriate location to reveal memory address at the stack, provided the script use printf.

To replicate this, simply run "perl tcpclientC.pl".

This will out following, 
RECIEVED: Palindrome server, 'quit' to quit:
RECIEVED:  bffffd64 bffffce8 8048545 0 0 bffff8e0 bffff8fa you got me!! is not a palindrome

the bffffd64, bffffce8 are the memory address printed by printf, 
and you got me! is the string on the Palindrome.c which attacker find and then inject the memory address into the buffer.
