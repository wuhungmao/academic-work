    Cryptography (approx. 30-90 minutes)

    [10 Marks] Public Key Cryptography (openssl on Kali)

    Please find the following:

    • Arnolds Certificate: arnoldscert.pem. View this via openssl x509 -in arnoldscert.pem -inform pem -text -noout.
    • BigBad Inc. Certificate: bigbadcert.pem. View this via openssl x509 -in bigbadcert.pem -inform pem -text -noout.
    • A Certificate Signing Request: req.pem. View this via openssl req -verify -in req.pem -text -noout.
    • Yes the files have a .txt extension so when you copy them, just remove the .txt extension.
    • These are in the openssl directory that shipped with the assignment. You can complete this on Kali.

    Your job, understand and document the following scripts (in this order):

    • openssl/caSetup
    • openssl/caAnswerCSR
    • makeCSR/doIt
    • crypto/doIt (you need to complete this one)
    The result of running these scripts leaves files in the openssl directory. Submit those files in this directory.
    Note: Please run each script from the directory the script is in.
    Note: Some certs are expired, this is fine for this question, proceed as if they were not expired.
    Hint: Read the scripts before running them.
