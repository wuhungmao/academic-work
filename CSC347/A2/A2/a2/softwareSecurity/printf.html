Example: printf format string vulnerability

The Vulnerability

  • Brief explanation: The printf format string vulnerability arises when the user provides a string that is used as the format string argument to printf(fmt, args);
  • Example code etc.: char *userInput = getInput(); printf(userInput);
  • How attacker exploits this: The attacker could provide a format string that includes format specifiers to see what information is on the stack address. or inject malicious code to be executed. For example, if the attacker provides the input "%x %x %x %x", the printf function will interpret this as a request to print four hexadecimal values from the stack, potentially revealing sensitive information.
  • Impact: CIAaa and some details Confidentiality: gain access to sensitive information on the stack. Integrity: modify the execution flow of the program. Availability: crash the program. Authentication: bypass authentication mechanisms. Authorization: gain unauthorized access to resources.

INSTRUCTIONS TO VERIFY VULNERABILITY BELOW

When the system requests: Input name: The user provides input: Arn %x ld The system responds with (for example): Hi Arn bfff23 ld If there was no printf vulnerability, we would expect: Hi Arn %x ld The difference is that the %x appears to be replaced with a hex value (bfff23) in the above example, indicating that a printf format string is derived directly from the users input at "Input name:"

The Fix

  • Explain the fix: We use a fixed format string in the printf function, such as printf("%s", userInput);
  • How the fix resolves the issue: This way, any malicious input is treated as literal characters and not interpreted by printf. so for example, if attacker enter "%x %x %x %x", it will be printed as "%x %x %x %x".
