# CSC207 — Boggle Game

University of Toronto Mississauga | Fall 2022

Full Boggle board game built in Java with JavaFX. Led a team using Scrum methodology.

## Features
- Randomized 4×4 letter board
- Dictionary-based word validation
- Score tracking with difficulty levels
- Timer per round

## Design Patterns Used
- Builder pattern for game construction
- MVC architecture (views/, model separated)
- Observer pattern for UI updates

## How to Run
```bash
javac -cp . BoggleApp.java
java BoggleApp
```
Requires Java 11+ and JavaFX on the classpath.

## Team & Process
5-person team. Used Scrum with sprint planning, user stories, and retrospectives. Created user personas and a detailed Phase 1 report (`project_phase1_template.pdf`).

## Tech Stack
Java, JavaFX, Scrum, OOP, Design Patterns
