# CSC384 — Introduction to Artificial Intelligence

University of Toronto Mississauga | Fall 2023

AI projects implementing classical search, constraint satisfaction, game-playing agents, and probabilistic reasoning.

## Projects

### Pacman AI Agent — Grade: 80/100
Search-based Pacman agent using DFS, BFS, UCS, and A* with custom heuristics.

### Futoshiki Puzzle Solver
Constraint satisfaction problem (CSP) solver for the Futoshiki inequality puzzle using backtracking with arc consistency (AC-3).

### Othello (Reversi) AI Agent
Adversarial search agent using Minimax with Alpha-Beta pruning for the Othello board game.

### Bayesian Network
Probabilistic inference in Bayesian networks: variable elimination and conditional probability queries.

## Tech Stack
Python, search algorithms, CSP, game trees, Bayesian inference
