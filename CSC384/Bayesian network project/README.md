# Bayesian Network

CSC384 — Introduction to Artificial Intelligence | University of Toronto Mississauga

## Description
Probabilistic inference engine for Bayesian networks. Computes conditional probability distributions given evidence using variable elimination.

## Features
- Network construction from CPT (conditional probability table) definitions
- Variable elimination algorithm
- Conditional independence queries
- Evaluation on real datasets in `data/`

## How to Run
```bash
cd revised_starter
python3 solution.py
```

## Key Concepts
Bayesian networks, conditional independence, variable elimination, marginalization, CPTs

## Tech Stack
Python, probability theory, graphical models
