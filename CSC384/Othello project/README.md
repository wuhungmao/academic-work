# Othello (Reversi) AI Agent

CSC384 — Introduction to Artificial Intelligence | University of Toronto Mississauga

## Description
Adversarial search agent for the Othello (Reversi) board game. Uses Minimax search with Alpha-Beta pruning to play optimally against an opponent.

## Features
- Minimax tree search to a configurable depth
- Alpha-Beta pruning for significant speedup
- Custom evaluation function (mobility, corner control, stability)

## How to Run
```bash
cd starter-code
python3 othello.py
```

## Key Concepts
Adversarial search, Minimax, Alpha-Beta pruning, game tree evaluation, zero-sum games

## Tech Stack
Python, game tree search, heuristic evaluation
